Annotation

In this Research Paper, I developed a decision-support framework for optimal multi-year defence budget resource allocation (i.e., the most efficient way of distributing resources each year under constraints) to achieve the pre-set target combat readiness level, in the form of a functional, workable Minimum Viable Product. 
The framework is based on a finite-horizon dynamic programming approach using a discrete Bellman equation, and it was implemented in the Python programming language with optimization for the Google Colab environment.
The study provides an original application of dynamic programming to long‑term defence readiness planning, integrating computational feasibility testing and global sensitivity analysis into a single, reproducible model.
Keywords: operations research, dynamic programming, Bellman equation, principle of optimality, budget allocation, Sobol sensitivity analysis, RAM wall.
